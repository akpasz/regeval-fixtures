# regeval-fixtures

Synthetic fixtures and a seed validation corpus for evaluating AI systems in
regulated financial workflows, beginning with a KYC/AML vertical slice.

**Build status: Stage 1 scaffold.** Schemas, corpus contract, licensing,
provenance, determinism harness, and verification tooling are in place; the
scenario corpus is not yet populated. The full README lands at Stage 6.

All content is synthetic and marked REGEVAL_SYNTHETIC. Licensing is split:
code under Apache 2.0 (LICENSE-CODE), content under CC BY 4.0
(LICENSE-CONTENT). See PROVENANCE.md and DESIGN_DECISIONS.md.
