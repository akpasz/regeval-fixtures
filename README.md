# regeval-fixtures

Synthetic fixtures and a seed validation corpus for evaluating AI systems in
regulated financial workflows, beginning with a KYC/AML vertical slice.

**Build status: Stage 3, batch 2, seven scenarios.** Validation corpus expansion is in progress; domain texture remains unratified. Schemas,
corpus contract, licensing, provenance, determinism harness, and verification
tooling are in place, AML-S01 remains the canonical seed scenario, and S02 onward extend the
corpus under the Stage 3 construction rules. Its domain realism is not yet approved: see DOMAIN_REVIEW.md. The
full README lands at Stage 6.

All content is synthetic and marked REGEVAL_SYNTHETIC. Licensing is split:

(LICENSE-CONTENT). See PROVENANCE.md and DESIGN_DECISIONS.md.
